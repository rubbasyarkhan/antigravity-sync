# 🚀 Antigravity Sync Workspace Guidelines

## 🎨 UI/UX & Design Guidelines
- **No Raw Emojis**: Never use raw unicode emojis in UI components or code. Always use professional vector SVG icons.
- **Layman-Centric UI/UX Psychology**: Always design interfaces to be intuitive, clean, and frictionless so a non-technical layman can operate the system effortlessly. Provide clear visual cues, simple language, and low cognitive load.

## 🏢 Coding Standards
- Maintain clean, modular, and testable code.
- Enforce strict error handling with graceful fallbacks.
